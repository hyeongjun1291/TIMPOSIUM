# 언어 모델 실행

## 다른 사람에게 보내는 방법

`Context-Lab-v2.zip`을 보내세요. 받는 사람은 **압축을 모두 풀고 `Context-Lab.html`을 Chrome 또는 Edge로 엽니다.** 다른 웹 소스 파일을 함께 복사할 필요가 없도록 화면·라이브러리를 HTML 하나에 넣었습니다.

1. 질문 하나를 입력합니다.
2. **답변 받기**를 누릅니다. 처음에는 모델을 자동으로 준비합니다(약 1GB 다운로드).
3. 준비가 끝나면 초안 생성·맥락 점검·필요한 수정까지 자동 진행됩니다.

맥락·용어·언어·비교 조건을 따로 입력할 필요가 없습니다. 질문 원문을 그대로 점검 근거로 사용합니다. 한글이 포함되면 한국어, 그 외에는 영어로 답하도록 설정하므로 다른 언어의 자동 감지는 지원하지 않습니다. 모델 설정은 선택적인 대체 실행 설정입니다.

API 키, Python, Node.js, Ollama는 이 기본 경로에 필요하지 않습니다. 다만 **최초 인터넷 연결, WebGPU 지원 브라우저/GPU, 모델 저장·실행 메모리**는 필요합니다. 1.5B 모델 다운로드는 약 1GB 수준, 경량 0.5B는 약 0.5GB 수준의 추정치입니다. 배포 ZIP에는 가중치가 없습니다. 모든 PC에서 파일을 열기만 하면 즉시 오프라인 추론한다는 보장은 아닙니다.

파일 자체의 화면과 작성 예시는 인터넷 없이도 열립니다. 실제 추론용 가중치는 사용자가 버튼을 누른 뒤 Hugging Face/MLC에서 받습니다. 질문과 맥락은 원격 추론 API로 보내지 않습니다. 브라우저 캐시가 삭제되거나 자산 재요청이 필요할 수 있어 완전 오프라인 재실행은 보장하지 않습니다.

## 파일 직접 열기에서 실패하면

- 최신 데스크톱 Chrome 또는 Edge에서 다시 엽니다. WebGPU 미지원·메모리 부족·회사 보안 정책은 HTML만으로 해결할 수 없습니다.
- 파일 출처 제한이 있으면 `start-mac.command` 또는 `start-windows.bat`를 실행합니다. 이 **대체 경로에는 Python 3가 필요**합니다. 서버와 브라우저가 자동으로 열립니다.
- 직접 명령을 쓸 경우 이 폴더에서 `python3 server.py --open` (Windows는 `py -3 server.py --open`). 주소는 `http://127.0.0.1:8765`입니다.
- macOS가 다운로드한 실행기를 막으면 운영체제 보안을 해제하지 말고, 터미널에서 위 Python 명령을 실행하세요.
- WebGPU 자체가 없으면 기존 Ollama와 로컬 실행기를 함께 사용하고 모델 설정에서 Ollama를 선택하세요. Ollama와 모델 설치는 이 패키지에 포함되지 않습니다.
- 8765 포트가 이미 사용 중이면 기존 로컬 서버를 종료한 뒤 다시 실행하세요. 종료는 서버 창에서 Ctrl+C입니다.

## 구현과 한계

원문을 보존한 anchor → 초안 → 근거 있는 점검 → 수정안 → 보수적 재검토 흐름입니다. 원문/초안 인용이 맞지 않거나 수정 과정이 실패하면 원래 답변을 유지합니다. 수정안이 생성됐다고 더 공정하거나 정확해졌다는 뜻은 아닙니다.

- `research/모델_구조와_언어편중_평가.md`: 모델 구조·언어 편중·성능 지표·구성요소 비교 설계.
- `research/연구_보고서.md`: 초록·배경·방법·개발 검증·한계·참고문헌을 담은 간단한 연구 보고서.
- `research/선행연구_검토.md`: 학술 연구 11편과 연결, 해석의 한계.
- `research/모델_설명과_방법론.md`: V2 구조, 비교 조건, 향후 효과 평가.
- `research/검증_기록.md`: 이 환경에서 실제로 확인한 것과 못 한 것.
- `evaluation/protocol_context_guard_v2_2.json`: 실행 설정과 주장 범위.
- `PACKAGE_MANIFEST.json`: 전달 파일의 SHA-256.

화면은 원문 근거 기반 수정을 자동 사용합니다. 기존 세 비교 조건은 코어 API에 남아 있습니다. **실행 기록 저장**은 질문·원문·모델 출력·프롬프트·설정을 JSON으로 내려받습니다. 이 파일에는 입력 내용이 포함되므로 공유 전에 내용을 확인하세요. 작성 예시는 실측이 아니어서 실행 기록으로 내보내지 않습니다.

새 가중치를 학습한 기반모델이 아니라 기존 Qwen의 추론 절차를 수정한 시스템입니다. 자세한 제한은 방법론 문서에 있습니다. 기존에 게시한 V1 사이트와 이번 로컬 V2 전달본은 구분하세요. 이번 요청은 로컬 전달본으로 처리했습니다.
