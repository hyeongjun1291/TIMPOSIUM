## 확인하지 못한 것

- 테스트 도구의 URL 보안 정책이 file:// 접근을 거절했다. HTML 더블클릭 후 실제 추론은 직접 검증하지 못했다. 이를 우회하지 않았으며, 별도의 허용된 localhost 경로에서 HTML과 추론을 확인했다.
- 추가 shell HTTP 경로 검사는 샌드박스 네트워크 권한 제한으로 실행되지 않았다. 브라우저를 통한 localhost 화면·추론 확인과는 별개다.
- Windows 실기기, 다른 GPU, Safari, 인터넷이 완전히 끊긴 재실행, 수신자의 더블클릭 실행은 미검증이다. 런처는 대체 수단이며 Python 3가 필요하다.
- 단일 HTML에 화면·코드·라이브러리를 포함했지만 가중치는 포함하지 않았다. 최초 준비에는 인터넷과 호환 GPU가 필요하다.
